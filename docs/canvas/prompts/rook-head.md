# Rook Head — prompt

There was no full prompt. In the same Codex session, the request was simply:

> make another scene

Codex chose the subject itself (a storm seascape with a lighthouse, a sea arch and a breaking Atlantic wave). It kept the technical conventions of its earlier pieces: one self-contained HTML file, Canvas 2D, 1920×1080, a seeded PRNG through `?seed=`, and no assets.
